# TTRPG source documents

Drop the Heldengilde TTRPG source material here: rules, classes, spells, lore, cities and factions.
Accepted formats: `.md`, `.txt`, `.yml`, `.yaml`, `.json`. The `heldengilde-ttrpg` MCP server searches this folder
(`search_ttrpg_rules_and_lore`) before any quest, item or skill is generated.
Source text may be Dutch; keep file names in English.
